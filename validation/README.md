# 当前版本验证

此目录保留当前功能的检查结果。旧布局、记忆光球和网页桌宠小窗的过期报告已删除。

- `launch.json`：一键启动、版本一致、当前资源、新静态服务与视频 Range。
- `native-pet*`：实际 Windows 桌宠、透明窗口、消息同步与回跳。
- `character-drag*`、`placement-clearance.json`：鼠标与触摸拖放、保存回退、放置范围。
- `discovery-*`、`one-click-*`：公众号、视频号、场景入口与完整展开过程。
- `public-moments-*`、`ui-layout-*`：公共朋友圈、好友主页、两列 / 三列会话。
- `pan-bounds*`、`stable-labels*`：相机范围与人物头顶提示稳定性。

JSON 中记录各次实测时间。保留的截图对应各项功能，不表示它们都在最近一次运行中重新截取。
