# 单名称场景胶囊与加载页

- 胶囊同一时间只显示一个场景名称，文字为 17px；森林使用树木图标，富士樱町使用雪山图标。
- 保留横向拖动，点击胶囊可直接切换；方向键、Home/End、取消拖动、模态禁用继续有效。
- 恢复完整场景加载页。加载开始时统一隐藏好友、群名、公众号、视频号、唱片机和车站等空间悬浮入口；新场景准备及画布交接完成后恢复。失败时移除加载页并恢复原场景。

| 实现 | 文件 | 验证 |
| --- | --- | --- |
| 单名称、大字、场景图标与交互 | `src/scene-switcher.js`、`scene-switcher.css` | `component.json`、`capsule.png`、`capsule-forest.png` |
| 加载页与两套场景入口统一隐藏 | `src/main.js`、`scene-theme.css` | `app-edge-cases.json`、`loading.png` |
| 往返后的会话、草稿、附件、未读和阅读位置 | 沿用场景切换生命周期 | `regression/browser.json` |

已通过构建、胶囊交互测试、场景边界测试及受影响的完整场景浏览器回归。入口隐藏检查覆盖旧场景与准备阶段新挂载的场景节点，也验证了加载失败恢复与重试。

`desktop.png`、`mobile.png` 为实际运行截图，`drag-scene-switch.webm` 为三次真实拖动切换录像。手机验证为 391×844 浏览器模拟及 CDP 触摸输入，未进行真实手机实测。
