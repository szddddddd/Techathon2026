# 点击后滑动的单按钮

固定尺寸的完整玻璃按钮，同一时间显示一个图标和场景名称；没有滑道和可拖动滑块。点击后原内容横向滑出，目标内容从另一侧滑入，总时长约 320ms。减少动态效果时仅淡入淡出。

实现：`src/scene-switcher.js`、`scene-switcher.css`。

构建、单按钮交互检查、实际场景切换与失败重试检查均通过。加载页面继续保留，加载时两套场景的悬浮入口均隐藏。

- `component.json`：整块按钮可点击、内容滑动、重复点击拦截、键盘与手机触摸。
- `app-edge-cases.json`：实际场景切换、失败回退、加载期隐藏入口。
- `capsule.png`、`capsule-forest.png`：实际按钮截图。
- `click-scene-switch.webm`：三次实际点击切换录像。

手机仅作 391px 浏览器模拟，未进行真实设备实测。
