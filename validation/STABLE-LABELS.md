# 拖动画面时的头顶标签稳定性

2026-10-15。

- 位置改为每个渲染帧更新，取消80ms节流，使用当帧相机矩阵投影。
- 标签贴合人物的屏幕位置，不对整段跟随进行滞后的插值；仅对避让偏移做约120ms平滑。
- 去除重叠时立即向左／右推开的逻辑，改为稳定的纵向避让；拖动和镜头惯性期间固定偏移，停止180ms后再整理。
- 被遮挡状态增加200ms稳定等待，避免转动时反复改变样式及气泡展开。
- ResizeObserver缓存标签真实宽度；位置保留子像素，边缘约束按实际宽度计算。

验证：构建通过；`npm run test:anchors` 通过。真实OrbitControls拖动采样85帧，四人各84个相邻可见帧全部更新位置，避让偏移变化均为0；页面错误为空。测试另检查状态点击不打开聊天、昵称正常打开聊天、391px手机无横向溢出。

结果：stable-labels.json。截图：stable-labels-drag.jpg、stable-labels-mobile.jpg。测试使用独立浏览器上下文，日常页面数据不被测试数据覆盖。
