# Techathon2026 · 林间来信 · 第二阶段 v1.3.1

本私有仓库按三个开发阶段归档；当前为第二阶段（场景与交互完善），来源于原项目提交 `caea101`。第一阶段保留在上一提交，第三阶段尚未提交。见 [阶段划分](./DEVELOPMENT-STAGES.md) 与 [第二阶段验证](./STAGE2-VALIDATION.md)。

三维森林社交网页，包含动物好友、聊天、朋友圈、公众号、视频号与 Windows 独立桌宠。

## ▶ 一键启动最新版

**下载并解压后，双击根目录的 [启动林间来信.cmd](./启动林间来信.cmd)。浏览器会自动打开最新网页。**

[![下载最新版](https://img.shields.io/badge/下载最新版-v1.3.1-52734d?style=for-the-badge)](https://github.com/szddddddd/Techathon2026/archive/refs/heads/main.zip)

| 点击上方按钮，下载并解压 ZIP | 双击 **启动林间来信.cmd** | 自动打开 **http://localhost:8080/** |

运行环境：Windows 10/11，先安装 [Node.js 22 LTS 或更新版本](https://nodejs.org/)。首次启动需要联网。

启动器自动准备依赖、构建当前版本、配置桌宠入口、启动服务并打开浏览器。以后仍双击同一个文件。服务窗口保持打开，关闭或 Ctrl+C 会停止服务；已有本项目服务时直接打开当前网页。**不要直接双击 index.html**。

GitHub 上的按钮用于下载，不能直接运行电脑中的程序。更新请重新下载 main，或执行 `git pull --ff-only`，然后再次双击启动文件。

唯一产品入口为 `index.html`，当前版本 **1.3.1**。旧版入口和过期预览的清理状态见 [清理清单](./CLEANUP.md)。`pet.html` 是桌宠运行页面，`asset-review.html` 是开发用模型检查工具，不是另一版网页。

## v1.3.0 · 山谷会客厅

陆地从 **566.47** 扩展到 **1186.10** 平方场景单位，约 **2.094 倍**。两座层叠主峰与低山脊围住山口泉流，右侧新增直径约 12 单位的年轮广场、来信树灯、弧形坐阶与树荫长椅。原木屋、桥、营地和两处发现设施保持原位；河流只向上游延伸。

**点击广场中央的四叶树灯 →「来广场坐坐」**，已添加的朋友伴随叶片转场抵达。仍可聊天、散步、拖动；聚会中的拖动只修改临时站位。再次点击树灯选择「结束聚会」，恢复原位置与镜头。点击外部仅收起浮层；聚会不保存，刷新使用原有站位。

沿广场后侧的缓坡可到约 **5.5 单位高**的观景台，主坡道最大 **21.1°**。人物可拖放到广场、山路和平台，脚底与地形一致；山峰只作景观。平台保留石板与周边细木护栏；原白色取景木框及「返回原视角」按钮已移除，可自由旋转、平移观景。

`src/world-surface.js` 统一轮廓、高度、法线与可行走区域，`src/valley-landmarks.js` 构建可编辑几何，`src/valley-social.js` 管理临时聚会与镜头。v1.3.0 扩建时未新增付费生成；v1.3.1 新增资产详见上文。已有 Rodin 道具共享模型资源。四叶灯按对应好友未读柔和发亮。

执行 `npm run test:valley` 查看地形、拖放、聚会、刷新、八角色容量、手机与性能检查。完整证据见 [山谷会客厅验收清单](./VALLEY-ACCEPTANCE.md)，截图和演示录像在 `validation/valley-*`。现有视频号短片仍是此前录制的内容。

原有清澈溪流、卵石河床、桥后小跌水及前景瀑布保留；`npm run test:river` 可独立回归水体。

## 主要操作

| 入口 | 功能 |
| --- | --- |
| 底部「好友」 | 添加团团、阿栗、小眠、山山；文字、图片、Emoji、表情包、草稿与未读 |

| 人物头顶状态 | 查看好友状态、文案与照片 |
| 底部「朋友圈」 | 好友和自己的动态、点赞评论；聊天标题「朋友圈」查看好友个人主页 |

## 森林交互更新

底部导航首次显示 3 秒，闲置后收成小胶囊；鼠标靠近、触摸点击或键盘聚焦即可展开。未读内容保留提示点，打开工作区时导航保持可见。

人物状态从头顶按钮展开为附近的轻浮卡，手机端停靠底部。照片、发布、编辑资料和分享逐层展开，Esc 每次返回一层。聊天草稿、未提交表单与发现阅读位置会保留；拖动场景时状态卡收起。系统的“减少动态效果”设置会关闭缩放位移动效。

## 好友与来信的森林

“好友”现在默认显示微信式会话列表，支持消息 / 通讯录、搜索、草稿、未读与独立添加好友页面。右键、手机长按或行尾更多按钮可置顶。

**置顶好友常驻，有未读来信的其他好友渐显入场。** 读完后，人物等聊天关闭，停留 1.2 秒再渐隐收纳；渐隐中有新消息会恢复。每次入场重新选择安全位置，拖动只修改本次停留位置，历史坐标仍保留在存储中。聚会也只召集有资格在场的朋友。

红点按未读量分档增大，叠信封最多四层，超过 99 条显示 `99+`。八种状态分别驱动跳跃、近似坐姿、躺卧、忙碌快步、玩叶子、听歌摇摆、热身运动和旅行散步。动作采用现有角色的程序形变，系统减少动态效果设置下保留静态姿态。

每位已添加好友都会独立主动来信：团团约 20–35 秒、阿栗 28–45 秒、小眠 40–65 秒、山山 32–55 秒，间隔随机，第一轮错开发出。每位好友轮换各自的日常话题，主动消息之间至少间隔 3 秒。沿用未读入场机制；「我」中的暂停演示和切到后台都会暂停计时，返回时不补发积压消息。

[实现与验收](./SOCIAL-PRESENCE-ACCEPTANCE.md) · [消息演示、32 种状态与录像](./validation/presence/index.html)

```powershell
npm run test:presence   # 置顶持久化、在场策略与浏览器机制
npm run test:actions    # 32 个角色状态和姿态交互
node scripts/compare-presence-performance.mjs
```

## Windows 桌宠

点击右上角「桌宠」打开电脑右下角的透明置顶小森林，可拖动、显示未读提醒、点击好友返回网页聊天。重复点击复用同一窗口。右键桌宠或托盘可隐藏、调整大小、设置提醒和退出。

启动器为当前用户注册 `forestletters://pet`；浏览器首次可能要求确认「打开应用」。项目移动目录后重新运行启动器。手动修复入口为 `npm run desktop:install`。这是本地开发启动器，目前没有独立安装包。

## 数据与演示

好友、聊天、照片、状态、动态与置顶保存到当前浏览器 IndexedDB；人物拖动仅影响本次停留，旧版保存的位置保留但不作为新入场位置，清除站点数据或更换浏览器会影响记录。好友回复和自动更新是本地演示，可在「我」暂停；没有真实微信接入、服务器账号或真人在线聊天。

桌宠通过 `127.0.0.1:47831` 与本机网页同步好友摘要和未读，仅允许当前配置端口的 `localhost` / `127.0.0.1` 来源。启动器在默认端口被占用时选择备用端口，并在本项目 `.forest-runtime.json` 保存配置；也可用 `FOREST_WEB_PORT` 指定端口。更换端口后须退出旧桌宠再唤起。模型和短片都在本地，网页运行时不调用 Rodin 付费接口。多标签页同时连接时保留当前活跃客户端，关闭该页面后约 8 秒可由另一页面接管。

## 开发与协作

本仓库用于阶段归档，当前 `main` 发布第二阶段。完整产品继续在原开发仓库推进。两个 agent 同时开发时，各自使用独立 worktree 与任务分支，由指定人员串行整合，正常 push，不覆盖协作者提交。

```powershell
npm ci
npm run launch          # 等同双击启动器
npm start               # 只启动网页服务
npm run build           # 构建当前版本并统一资源版本号
npm run desktop         # Electron 主窗口与桌宠
```

`package.json` 是版本来源，锁文件与页面 forest-version 一致。构建时更新网页和桌宠 JS/CSS 版本号；发布更新需调整版本并重新构建。

```powershell
npm test                # 社交、朋友圈和发现数据
npm run test:valley     # 扩展面积、坡面、聚会、观景台、手机、帧率
npm run test:launch     # 一键入口、版本与资源
npm run test:drag       # 鼠标、触摸拖放和保存回退
npm run test:placement  # 放置范围与实体阻挡
npm run test:pet        # 实际 Windows 桌宠与消息同步
npm run test:browser    # 阅读、视频、分享和手机布局
```

浏览器测试依赖已声明的 Playwright 和本机 Edge，无需开发机绝对路径。先启动网页服务，再执行 `npm run test:regression`；默认依次验证数据、通知摘要、网页桥接、原生桌宠及冷启动。使用 `FOREST_TEST_URL` 指定服务地址，`FOREST_TEST_OUTPUT` 指定证据目录（默认 `.test-results/`，不覆盖正式验证记录）。原生测试使用隔离 profile，不安装系统协议。`npm run test:launch` 需已有测试服务；`node scripts/test-port-fallback.mjs` 可独立验证端口占用回退。`assets/` 保存现用模型、素材及来源，`src/` 是可编辑源码，`validation/` 保存验证记录。Git 提交历史用于回看修改，不作为旧版启动入口。历史文件清理状态与完整列表见 [CLEANUP.md](./CLEANUP.md)。
