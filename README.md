# 林间来信 · 三维森林社交原型

打开 http://localhost:8080/ 。运行 `npm start`，构建 `npm run build`，数据测试 `npm test`，角色审计 `npm run audit:social`。

## Windows 桌宠

右上角「桌宠」直接唤出电脑桌面右下角的独立透明置顶窗口，浏览器最小化后仍能显示，可以拖动。右键桌宠或任务栏托盘可隐藏、调整大小、关闭置顶、设置提醒和退出。网页不再展开三维小窗。

每台 Windows 电脑首次运行 `npm ci`、`npm run desktop:install`，为当前用户注册 `forestletters://pet`。之后点击网页「桌宠」即可启动，浏览器可能要求确认「打开应用」。已运行时直接显示原窗口，不重复启动；协议启动只显示桌宠，不另开一个森林主窗口。项目移动目录后需要重新运行安装命令。此处是本地开发启动器，尚未打包为可分发安装程序。

`desktop/pet-bridge.cjs` 在 `127.0.0.1:47831` 提供本机连接，仅允许 `http://localhost:8080` 和 `http://127.0.0.1:8080` 的网页交换好友、最近消息和未读数，社交数据仍由原浏览器 IndexedDB 保存。桌宠点击好友后通过该连接打开网页现有会话；没有活跃网页时打开桌面主窗口。桌宠保留最近一次同步的本地摘要，无未读时保留一位好友陪伴。通过托盘「退出」结束本机进程后，再次点击网页可以重新唤出。

实现见 `src/web-pet.js`、`desktop/main.cjs`、`scripts/install-desktop-launcher.ps1`。`npm run test:pet` 实际启动 Electron、检查透明桌宠窗口、消息同步、会话回跳、重复唤出及来源限制；`npm run test:desktop-bridge` 检查桌面主窗口接口。验证记录与截图见 `validation/native-pet*`，旧 `validation/web-pet*` 属于之前网页小窗的历史证据。

## 公共朋友圈

底部「朋友圈」入口汇总自己与所有已添加好友的动态，按发布时间倒序展示。每条显示作者、签名、发布时间、图文、点赞及评论；新动态数提示在入口显示。好友个人主页与公共朋友圈共用动态及互动数据。

可在公共页直接发表朋友圈。点击好友作者进入其个人主页，点击「聊聊这条」进入对应作者的聊天并分享动态。点击弹窗外关闭。所有内容依然保存在当前浏览器，未接入真实微信。

## 最新界面：好友 / 聊天 / 可收起的朋友圈

打开好友后，左侧好友列表与聊天窗口作为两列整体居中；点击聊天标题栏的「朋友圈」展开右侧第三列，再点「收起」恢复两列。切换好友默认收起朋友圈并保留各自草稿。

朋友圈改为个人主页：封面、昵称、头像、个性签名及按日期排列的图文动态，包含点赞、评论与「聊聊这条」。自己的朋友圈也采用同样排版。

所有弹窗取消叉号，点击窗外关闭；照片大图关闭后保留原会话。手机保留好友侧栏，在聊天与朋友圈之间切换。验证记录见 `validation/UI-LAYOUT-ACCEPTANCE.md`。

## 慢慢散步

在场景中按住人物本体并拖动，可将好友放到新的陆地位置；单击依然进入聊天。拖动时人物浮起，绿色落点表示可以放下，红色表示河面、实体障碍或人物重叠。允许站在陆地小路和草丛中，手动放置以身体半径检测，物体额外间距为 0.06、人物间距为 0.15；树木、岩石和建筑实体仍然检查，草与蕨叶不当作硬障碍。无效放置、Esc、触摸取消或失焦会回到原位，保存失败也会回退。拖动期间锁定相机并暂停散步，放置成功后保存新位置，重新生成附近散步路线；新位置重载与后续散步共用放宽后的检测，添加其他好友不会重置已摆放的人物。会话关闭回到场景后可继续拖动。手机支持直接触摸拖放。

实现位于 `src/character-drag.js` 与 `src/social-characters.js`，位置通过 `setCharacterPosition` 进入 IndexedDB。执行 `npm run test:drag` 检查真实鼠标和触摸手势、碰撞、取消、保存回退及刷新恢复；截图与报告位于 `validation/character-drag*`。

`npm run test:placement` 使用真实地形与道具，在相同的 1161 个网格点比较狐狸可放置范围：20 → 342 个；这表示该模型与采样条件下的范围变化，并非任意人物的连续可用面积。河面、悬崖外、木屋内部、篝火和人物重叠的阻挡检查通过。记录见 `validation/placement-clearance.json`。

四位好友现在会在各自附近沿安全路线缓慢行走（每秒约0.24–0.29场景单位），走完一段停留2–5秒。模型腿部有轻微交替迈步和身体摆动；这是现有网格的程序动画。选中聊天时停止位移并面向镜头，关闭后继续。路径允许沿陆地小路走动，避开河面、实体障碍与其他角色；后台和减少动态偏好下暂停。`src/companion-walk.js` 提供路径图和移动间距检查，角色审计包含四人散步路线。

## 如何体验

1. 左下角「好友」搜索昵称或 ID，添加团团、阿栗、小眠、山山。新浏览器初始为空，当前验收浏览器已添加四位演示好友。
2. 点击角色、昵称或消息气泡进入会客空间；左侧发文字、Emoji、表情包、图片，右侧点击记忆光球查看朋友圈并点赞评论。
3. 点击头顶状态徽章查看状态文案和图片。右下角「我」可修改资料、发布/结束状态、发布朋友圈、查看自己的记忆。
4. 「我」中的演示控制可暂停/继续/重播预设故事。回复是本地模拟，不连接微信或真人账号。数据与上传图片保存在当前浏览器的 IndexedDB。
5. 空白处拖动旋转、滚轮缩放、右键平移；关闭会话返回原镜头。手机使用聊天/记忆页签。

## 布局与遮挡

- 木屋和帐篷分区，推车、木箱、木桶独立留缝；营火和凳子移出主路。
- 门前、帐篷入口、桥头及左岸步道设置通路保留区。
- 树木缩放/移动，避免树根越岸及树冠穿入房屋；小花通过保留区自动避让。
- 假山、晶簇、大蕨草分别摆放，排除植物与岩石/建筑的检测交叠。

## 林间发现：公众号与视频号

底部「发现」进入公众号和视频号，或点击场景中的森林报刊亭／溪谷放映场。

- 三个原创公众号、九篇完整文章；搜索、订阅、字号、阅读进度、点赞、留言和收藏。
- 四位动物作者、六条真实场景短片；推荐／关注／朋友，连续观看、进度拖动和评论。
- 报刊亭、幕布、放映机和坐垫均为 Three.js 源码构建的可编辑几何；幕布与完整播放器共享同一个视频元素。
- 文章和视频可分享给指定好友，或附言转发朋友圈，卡片可重新打开；「我」提供关注、收藏和浏览足迹。
- 数据仅存当前浏览器 IndexedDB。视频与图片为本地静态资产；不接入微信，不提供内容上传、直播或后台。

验证：`npm test`、`node scripts/audit-discovery.mjs`、`node scripts/test-discovery-browser.mjs`。浏览器测试使用独立无痕上下文，测试好友和评论不会写入日常使用页面。

素材复现：`npm run record:discovery`，使用独立 `?capture=1..6` 场景（不读取用户数据库）录制 540×960、24fps 目标、12 秒短片。需要本机 Edge、Playwright 和 imageio_ffmpeg；脚本中运行时路径按本机配置。录制结果用 FFmpeg 无损重封装后保存，并加入原创合成环境声（非实地录音，默认静音）。播放时加载本地 Blob，兼容默认 Python 静态服务器不支持 Range 请求的情况。

功能与验证证据见 `validation/DISCOVERY-ACCEPTANCE.md`。


场景入口采用一次连续展开：待机板面就是简略公众号／视频号页面，点击后镜头推进约750ms，第550ms起木框与内容渐变放大，约1150ms进入正式窗口。窗口外点或Esc会完整反向收回并恢复镜头。公众号用浅木框，视频号用深木框；阅读位置、评论草稿和视频暂停意愿保留。`npm run test:boards` 验证完整进退、快速切换及手机适配；过程录屏和证据见 `validation/ONE-CLICK-ACCEPTANCE.md`。
