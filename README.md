<details>
<summary>开始本地体验</summary>

Windows 安装 Node.js 22+，双击 **启动林间来信.cmd**；桌宠使用 **启动桌宠.cmd**。

或在项目目录运行：

```bash
npm install
npm run build
npm start
```

打开 [localhost:8080](http://localhost:8080/)。
