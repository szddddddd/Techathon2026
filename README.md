# 林间来信 · 三维森林社交原型

打开 http://localhost:8080/ 。运行 `npm start`，构建 `npm run build`，数据测试 `npm test`，角色审计 `npm run audit:social`。

## 慢慢散步

四位好友现在会在各自附近沿安全路线缓慢行走（每秒约0.24–0.29场景单位），走完一段停留2–5秒。模型腿部有轻微交替迈步和身体摆动；这是现有网格的程序动画。选中聊天时停止位移并面向镜头，关闭后继续。路径允许沿陆地小路走动，避开河面、实体障碍与其他角色；后台和减少动态偏好下暂停。`src/companion-walk.js` 提供路径图和移动间距检查，角色审计包含四人散步路线。

## 如何体验

1. 左下角「好友」搜索昵称或 ID，添加团团、阿栗、小眠、山山。新浏览器初始为空，当前验收浏览器已添加四位演示好友。
2. 点击角色、昵称或消息气泡进入会客空间；左侧发文字、Emoji、表情包、图片，右侧点击记忆光球查看朋友圈并点赞评论。
3. 点击头顶状态徽章查看状态文案和图片。右下角「我」可修改资料、发布/结束状态、发布朋友圈、查看自己的记忆。
4. 「我」中的演示控制可暂停/继续/重播预设故事。回复是本地模拟，不连接微信或真人账号。数据与上传图片保存在当前浏览器的 IndexedDB。
5. 空白处拖动旋转、滚轮缩放、右键平移；关闭会话返回原镜头。手机使用聊天/记忆页签。

## 实现与证据

- `src/social-store.js`：统一事务、IndexedDB、图片 Blob、24 小时状态、演示调度。
- `src/social-characters.js`：四种实际 GLB、角色拾取、高亮、相机、真实几何安全站位。
- `src/social-ui.js` / `social.css`：好友、聊天、状态、发布、记忆光球和响应式界面。
- `validation/SOCIAL-ACCEPTANCE.md`：需求映射、实测数据、截图与边界。
- `assets/rodin-friends/review.html`：四款模型的正反面检查页。
- `records/rodin-friends/summary.json`：四次生成，共 2.0 credits；`curation.json` 记录狐狸/兔子/熊尾部的离线修整，原始模型保留。
- `?stress=1` 为无数据写入的八角色渲染检查入口，仅用于开发验证。

保持本轮前的桥跨度 9.24、高度 3.8、桥面宽度 3.92；河宽为上一宽河版本的 0.7 倍。没有修改既有场景比例。

## 布局与遮挡

`src/layout.js` 是统一的摆放与净空定义，网页和审计脚本共同使用。所有资产以实际GLB几何确定底部与尺寸。

- 木屋和帐篷分区，推车、木箱、木桶独立留缝；营火和凳子移出主路。
- 门前、帐篷入口、桥头及左岸步道设置通路保留区。
- 树木缩放/移动，避免树根越岸及树冠穿入房屋；小花通过保留区自动避让。
- 假山、晶簇、大蕨草分别摆放，排除植物与岩石/建筑的检测交叠。
- 新桥按实测跨度、宽度和高度接岸；桥台有意嵌入岸体形成支承，移除桥下穿插的旧岸石。
- 陆地面积保持567.808，比最初版增加42.018%，新增空地未密集填满。

## 主要文件

- `src/layout.js`：资产位置、尺寸、保留区和通路。
- `src/rodin-props.js`：13类本地模型加载、色调/粗糙度适配、统一放置。
- `src/main.js`：灯光、相机、动画和交互。
- `src/terrain.js`：两岸地形、道路、流水与瀑布。
- `src/architecture.js`、`src/nature.js`：营火、植被细节及基础回退模型。
- `assets/rodin/`：生成模型原件和网页使用副本。
- `scripts/generate_rodin_expansion.py`、`scripts/generate_rodin_landmarks.py`：本轮可续传生成入口。
- `previous-rodin-v2/`：本轮修改前源码备份。

场景保持手绘低多边形森林风格。原参考图无法确定的背面、尺度和内部结构为合理推断；没有第一人称碰撞行走或屋内探索。
