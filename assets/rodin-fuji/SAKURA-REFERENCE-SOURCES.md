# 用户参考图樱花树：裁图、生成与筛选

用户提供 1080×1600 的 3×5 樱花图集，要求只使用上面六棵。此次直接按前两行从左到右裁切用户图片，未另做生图替换参考。每棵的 `crop.png` 是对应 360×320 原像素裁图；`reference.png` 等比放大并补黑边到 720×720，作为 Rodin 输入。

- 原图、裁图坐标、输入哈希和六图预览：`sakura-reference-six/`。
- 裁图脚本：`../../scripts/crop-reference-sakura.py`。
- 生成脚本：`../../scripts/generate-reference-sakura.mjs`。复用现有 OAuth，断点续查任务；下载重试不会重提交生成。
- 六次均为 `Gen-2.5-Medium / Raw / 30,000 / GLB`。每个资产目录保存提示词、参考、原始 `source.glb`、优化 `scene.glb`、三视图与清单。
- 场景版仅将纹理缩至 1024，保留原始几何。生成与场景文件的哈希分别写入清单。
