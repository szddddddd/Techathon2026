# 工程整理计划

目标：让新贡献者可以从清晰的目录、文档和命令开始开发 WeRoam，并保留现有 Web、桌面、Android 入口。

## 必做工作与验收

- [x] 按职责整理 `src/`，样式归入 `src/styles/`；同步模块引用、HTML、构建与 Android 打包路径。
- [x] 测试独立到 `tests/`，工具留在 `scripts/`；保留原 npm 功能命令。
- [x] 构建产物取消 Git 跟踪，本机数据、密钥、签名、演示稿不进入源码提交。
- [x] 补齐快速开始、目录导航、开发、贡献、安全与许可说明，区分代码许可和素材授权。
- [x] 增加基础 CI、Issue/PR 模板和编辑器约定。
- [x] 用干净依赖安装、构建、离线测试与浏览器加载检查形成验证证据，见 [验收记录](../validation/engineering-layout-2026-10-19.md)。

## 约束

- 不读取 `C:\Users\user\Desktop\world2`。
- 保留本地未跟踪的 `weroam-slides/` 与私有运行目录。
- 不触发实际图像或 Rodin 生成，不改用其他凭据来源。
- 不新增产品功能或改写 Android 生成链路；如有实现与既有规范不一致，在文档中准确记录。
- 提交与推送遵循用户明确指令；不自动发布或部署。

## 不在本次范围

补齐未知第三方素材授权、真实平台账号验收、Android/VR 实机发布及历史 Git 凭据审计。
