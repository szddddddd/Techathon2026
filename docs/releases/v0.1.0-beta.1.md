# WeRoam v0.1.0-beta.1

首个同时提供 Windows 桌面安装器与 Android APK 的 beta 预发布。下载安装包即可运行基础体验，无需克隆代码或安装开发环境。

| 下载 | 适用设备 |
| --- | --- |
| [Windows 一键安装 EXE](https://github.com/szddddddd/Techathon2026/releases/download/v0.1.0-beta.1/WeRoam-0.1.0-beta.1-windows-x64-setup.exe) | Windows 10 / 11，x64 |
| [Android 安装 APK](https://github.com/szddddddd/Techathon2026/releases/download/v0.1.0-beta.1/WeRoam-0.1.0-beta.1-android.apk) | Android 8.0+ |
| [SHA-256 校验清单](https://github.com/szddddddd/Techathon2026/releases/download/v0.1.0-beta.1/SHA256SUMS.txt) | 检查下载文件完整性 |

Windows：双击 EXE，自动为当前用户安装、创建桌面与开始菜单快捷方式并启动。Android：下载 APK 后点击安装，按系统提示允许本次来源。系统 WebView / 显卡需要支持 WebGL 2。完整[安装指南](https://github.com/szddddddd/Techathon2026/blob/main/docs/INSTALL.md)。

## 本版内容

- 森林、富士樱町、理想城三场景，昼夜变化、好友角色和本地消息。
- Universal Inbox 演示、创意工坊与场景建筑。
- Windows 独立桌宠、托盘与桌面邮箱入口，安装包内含 Electron。
- Android 离线网页资源与触控适配；APK 沿用既有签名，versionCode `1030106`。
- 清理旧场景与冗余资源，统一源码结构和文档导航；包内不含开发者服务密钥。

## 安装与升级说明

- Windows 安装器尚无发布者代码签名，系统可能显示未知发布者或 SmartScreen 提示；请核对来源和校验值。关闭主窗口会留在托盘，退出请使用托盘菜单。此版不自动更新，后续从 Release 下载升级。
- Android APK 已完成应用签名及签名校验。覆盖安装要求相同签名；签名冲突时不要直接卸载含重要本地数据的旧应用。卸载会删除手机数据。
- 基础体验无需服务凭据；头像生成、真实邮箱及邮箱 Agent 需要各自的本机配置与授权。Windows 与 Android 的本地数据不自动同步。
- 项目仍为产品原型，没有接入完整的真实微信 / QQ 社交私信；本次包未完成实体设备安装验收，不能保证所有设备的性能。
- 原创代码使用 ISC，第三方素材保留各自权利；来源及待补授权见[第三方资源说明](https://github.com/szddddddd/Techathon2026/blob/main/docs/THIRD-PARTY-RESOURCES.md)。

`release-manifest.json` 记录发布包对应源码提交、大小和 SHA-256。构建与打包过程见[发布指南](https://github.com/szddddddd/Techathon2026/blob/main/docs/RELEASING.md)。
